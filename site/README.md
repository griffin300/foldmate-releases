# Foldmate website (draft)

A small static site: plain HTML and one CSS file. There's no build step, no JavaScript, no trackers and no
external fonts or scripts. It follows the system's light or dark mode.

To view it, open `index.html` in a browser. It isn't published anywhere yet.

Pages:

- `index.html`: home
- `features.html`: features
- `privacy.html`: what goes online, and when
- `download.html`: links to the latest release on GitHub
- `faq.html`: the same answers as the README's Troubleshooting and FAQ

All copy comes from the README in this repository. When the README changes, update these pages to match.
