Troubleshooting and FAQ

Press F1 in Foldmate for its Help, which works offline. If you still need help, see Support.

Windows says "Windows protected your PC". What do I do?

Foldmate isn't code-signed yet, so Windows SmartScreen may stop the installer with this message. Click More info, then Run anyway.

Windows blocks the installer and there's no Run anyway button.

That's Smart App Control, which is on for some new Windows 11 PCs. It blocks apps that aren't signed, so Foldmate can't run while it's on. Whether to turn it off is up to you. Read Microsoft's guidance first: on many PCs it can't be turned back on without resetting Windows.

Chat works, but web research doesn't.

Web research runs in Windows Subsystem for Linux (WSL), and it needs virtualization turned on in your PC's BIOS/UEFI. Without it, chat still works, and Foldmate tells you which setting to turn on. On a PC with an ARM processor, chat works but web research doesn't. Right after you install, web research may still be setting up: it finishes in the background during the first few minutes. OpenCode needs WSL and virtualization too.

How do updates work?

Foldmate checks for new versions in the background. When one is ready, a small arrow appears next to Foldmate's name in the sidebar. Choose it to download the update, then choose Restart to update. Downloading and installing each need your click. Most updates download only the files that changed: 1.1.17 is about 19 MB from 1.1.16, 1.1.15 or 1.1.14. From an older version, the update downloads the full installer (about 0.88 GB). Only releases signed with Foldmate's key install, and each file is checked before it's used.

Is there a Mac version?

Yes, as a preview. It's version 1.1.15, built and tested on Apple silicon (an M1). Download Foldmate-1.1.15-mac.dmg from the 1.1.15 release.

It isn't notarized by Apple yet, so macOS stops it the first time: Control-click Foldmate in Applications and choose Open, or open System Settings › Privacy & Security and choose Open Anyway. Some features are Windows-only for now, including computer use, Share control, the screen-saver handling for your phone, PC commands, and the phone's video and computer sound.

What changes when I turn on Through Tor?
  • Web research: by default it goes direct, and sites see your IP address and what you search. Through Tor is the private route. It never falls back to direct.
  • Model downloads, cloud models and connected services: each can go direct (the default) or Through Tor. For cloud models, you choose per provider.
  • Update checks go directly to Foldmate's releases on GitHub, not through Tor. GitHub sees your IP address.
  • Your phone: Remote works through Tor with no account, or straight over your own Wi-Fi. On the same Wi-Fi, you hear this computer at full quality (48 kHz stereo). Over Tor, sound goes up to 9.6 kHz.
How do I stop everything from going online?

Turn on Settings & tools › This computer › Local-only lockdown. It stops everything in the privacy table at once. Chat with your local model keeps working.

Do I need a graphics card?

No. Models run on the processor too, just more slowly. 16 GB of RAM or more is recommended, and 8 GB works with small models.

Can I use models I already downloaded for LM Studio or Ollama?

Yes. Models already in LM Studio's or Ollama's folders show up in Models where they are. Nothing is copied.
