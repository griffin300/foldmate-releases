Privacy: what goes online, and when

Nothing you type leaves this PC unless you choose a cloud model or a connected service.

Your chats are encrypted on your disk

The key is protected by your Windows account.

No telemetry or analytics

Foldmate doesn't report what you do, and it never sends a support report for you.

Models run on this PC

A cloud model is only used when you pick one, and Foldmate asks before it sends an existing chat.

Web research goes direct by default

Turn on Through Tor for the private route. It never falls back to direct.

You decide what it may do

Each chat has an approval mode: Ask every time, Approve for me, or Full access.

More details

  • Support reports: Settings & tools › Support › Support report shows a short summary of your PC and Foldmate. Read it, save it, and attach it yourself. Foldmate never sends it, and it leaves out your chats, keys and passwords.
  • Updates: Foldmate checks for new versions directly, not through Tor. Only releases signed with Foldmate's key install, and each file is checked before it's used.
  • Your phone: Remote is off until you turn it on. Photos you send from the iPhone app go only to this computer's own model and aren't saved.
  • Email: you see the whole email, and can edit it, before it goes. With Gmail, Foldmate can send mail but never read it.
  • If you uninstall: your chats, settings and models are kept, so installing again picks up where you left off. Delete that folder yourself if you no longer need it. The install guide says where it is.
