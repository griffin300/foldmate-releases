Install on Windows

  1. Download Foldmate-Setup-1.1.17.exe from the latest release.
  2. Run it. Foldmate isn't code-signed yet, so Windows may stop it:
    • "Windows protected your PC" (SmartScreen): click More info, then Run anyway.
    • Smart App Control (on some new Windows 11 PCs): it blocks apps that aren't signed and doesn't offer Run anyway, so Foldmate can't run while it's on. Whether to turn it off is up to you. Read Microsoft's guidance first: on many PCs it can't be turned back on without resetting Windows.
  3. The installer sets up what Foldmate needs: Microsoft's Visual C++ runtime, and Windows Subsystem for Linux (WSL), which Foldmate's web research engine runs in, if your PC doesn't have them. Windows downloads WSL from Microsoft. Windows may ask for permission (up to twice). A restart may be needed.
  4. Foldmate opens. Its AI engine comes with it, and web research finishes setting up in the background during the first few minutes. Foldmate recommends a model that fits your PC and downloads it only when you choose Download and load.

What you need

  • Windows 11, 64-bit. Windows 10 may work, but it isn't supported. On a PC with an ARM processor, chat works but web research doesn't.
  • RAM: 16 GB or more is recommended. 8 GB works with small models.
  • Virtualization turned on in your PC's BIOS/UEFI, for web research. Without it chat still works, and Foldmate tells you which setting to turn on.
  • Disk: about 15 GB free to install and set up, plus your models. A small model is about 1–2 GB.
  • A graphics card is optional. Models run on the processor too, just more slowly.

Open the Mac preview

The Mac preview isn't notarized by Apple yet, so macOS stops it the first time. Control-click Foldmate in Applications and choose Open, or open System Settings › Privacy & Security and choose Open Anyway.

Some features are Windows-only for now, including computer use, Share control, PC commands, and the phone's video and computer sound.

Your iPhone (beta)

Install Foldmate on your iPhone from the App Store. On your PC, turn on Settings & tools › Remote, then open Remote on the phone and scan the code Foldmate shows.

Updates

When an update is available, a small arrow appears next to Foldmate's name in the sidebar. Choose it to download the update, then choose Restart to update. Most updates download only the files that changed: 1.1.17 is about 19 MB from 1.1.16, 1.1.15 or 1.1.14. From an older version, the update downloads the full installer (about 0.88 GB).
