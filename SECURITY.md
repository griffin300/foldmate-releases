# Reporting a security problem

Please report security problems in Foldmate privately, not in a public issue.

## How to report

1. Open this repository's **Security** tab and choose **Report a vulnerability**, or go straight to
   https://github.com/griffin300/foldmate-releases/security/advisories/new.
2. Describe the problem:
   - which part it affects (the Windows app, the Mac preview, the iPhone app, the installer or updates);
   - your Foldmate version, and your Windows or macOS version;
   - the steps that show the problem;
   - what someone could do with it.
3. Leave out your own chats, keys and passwords.

Only you and the people who look after Foldmate can see a private report. GitHub explains how private reports
work in [Privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

If you don't see **Report a vulnerability**, open an issue that says only that you have a security problem to
report, with no details, and we'll arrange a private way to send it.

## Please

- Don't post the details publicly until it's fixed.
- If you can, check the problem on the latest version of Foldmate first.
